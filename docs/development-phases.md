# Development phases

Each phase ends with executable checks, error fixes, a change list, and a clear handoff.

1. Scaffold and tooling.
2. Dataset manifests, licensing notes, conversion, and integrity checks.
3. Reproducible YOLO baseline with real evaluation artifacts.
4. Image validation, preprocessing, ORB matching, homography, and alignment tests.
5. Modular component detection and reference comparison.
6. Dataset-supported advanced defect and trace analysis.
7. FastAPI routes, SQLAlchemy models, SQLite/PostgreSQL persistence.
8. Accessible React dashboard and API integration.
9. Reproducible PDF inspection reports.
10. Full tests, container hardening, CI, and operational documentation.
